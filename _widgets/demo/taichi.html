☯ <tai-chi/> 太极阴阳轮转

《周易》曰：「易有太极，是生两仪，两仪生四象，四象生八卦。」 本组件以纯 CSS 关键帧实现阴阳鱼无穷循环旋转、阴阳互转、鱼眼相换之妙。 提供 --size / --dot / --yin / --yang / --duration 五枚 CSS 变量，可穿透 Shadow DOM 自由订制尺寸、点睛、阴阳色调、轮转节律。

1. 默认轮转 (size=360px, duration=8s)

「天地氤氲，万物化醇；男女媾精，万物化生。」

2. 尺寸定制 (--size / --dot)

小阴阳 140 px

--size: 140px; --dot: 24px;

中阴阳 220 px

--size: 220px; --dot: 38px;

大阴阳 300 px

--size: 300px; --dot: 50px;

4. 轮转节律 (--duration)

急转 2s

急速旋转 · 阴阳速变

常态 8s

默认节奏 · 中和之道

徐缓 24s

缓慢轮转 · 静观沉思

停滞

近乎凝固 · 静若磐石

5. 动态调和 · CSS 变量实时穿透

所有变量仅作用于当前组件实例：通过 inline style 为 tai-chi#dyn 设置 --size / --dot / --yin / --yang / --duration，即可见阴阳之变化、流转之疾徐。
